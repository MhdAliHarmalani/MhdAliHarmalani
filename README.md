**[CRx Game — Chain-Reaction Strategy Game](https://github.com/MhdAliHarmalani/CRx-Game)**

A Pygame implementation of the classic chain-reaction strategy game. The core engineering challenge was
cascading cell explosions: implemented as an iterative queue-based state machine instead of recursion,
avoiding stack overflow and UI freezes on large chain reactions. Per-cell critical mass is derived from
grid topology (corner/edge/inner cells), with dual win-condition logic (elimination and full-board
domination). *Personal project, Python/Pygame.*
